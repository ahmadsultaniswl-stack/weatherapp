# Weather App ⛅ — WeatherCast: Live Weather with Location Lookup

A Flutter weather app that fetches live weather data from a public API, with city search and current-location lookup, plus a detailed weather breakdown screen.

## ✨ Features

- 🔍 **City search** — search any city by name for live weather
- 📍 **Current location weather** — one-tap "My Location" lookup using device GPS
- 🌡️ **Core weather info** — temperature, "feels like", pressure, humidity, wind speed, and sky condition
- 📊 **Detailed weather breakdown** — cloud cover, visibility, wind direction, min/max temperature
- 🌅 **Location & system info** — country, sunrise/sunset times, timezone (UTC offset), and last-updated timestamp

## 🚀 Getting Started

```bash
# Clone the repo
git clone https://github.com/ahmadsultaniswl-stack/weatherapp.git
cd weatherapp

# Install dependencies
flutter pub get

# Run the app
flutter run
```

> Note: You'll need your own API key for the weather API — check the API service file in `lib/`.
